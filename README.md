# 🔐 자물쇠

> 학교 건물 안에서 단서를 찾고, 비밀번호를 풀어 잠긴 공간을 열어가는 1인칭 3D 방탈출 게임

`자물쇠`는 2022년 WAP 게임 프로젝트 3팀에서 제작한 Unity 팀 프로젝트입니다.
플레이어는 학교 내부를 돌아다니며 열쇠, 종이 단서, 모니터 힌트 등을 확인하고 여러 공간을 오가며 퍼즐을 해결합니다.


| 항목 | 내용 |
| --- | --- |
| 🎮 장르 | 1인칭 3D 방탈출 |
| 🛠️ 개발 환경 | Unity 2021.3.1f1 |
| 💻 개발 언어 | C# |
| 🧩 핵심 요소 | 탐색, 단서 확인, 열쇠 획득, 비밀번호 입력, 씬 이동 |
| 🏫 배경 | 학교 건물 내부 |
| 👥 개발 형태 | WAP 게임 프로젝트 팀 프로젝트 |

## 🚪 게임 진행 방식

1. 학교 내부 공간을 탐색합니다.
2. 문, 종이, 모니터, 열쇠 같은 오브젝트를 `E` 키로 조사합니다.
3. 단서에서 얻은 정보를 바탕으로 자물쇠 비밀번호를 입력합니다.
4. 조건을 만족하면 새로운 방이나 층으로 이동할 수 있습니다.
5. 여러 씬을 오가며 다음 단서를 찾고 게임을 진행합니다.

<br>

## 🔎 주요 구현 내용

### 플레이어 이동과 시점 제어

`CharacterController`를 이용해 1인칭 이동을 구현했습니다.
마우스 입력으로 카메라를 회전하고, 점프와 천천히 걷기 기능도 함께 처리합니다.

- 기본 이동 속도와 저속 이동 분리
- 점프 입력 처리
- 마우스 Y축 회전 제한
- 이동 중 발소리 재생

<br>

### Raycast 기반 상호작용

카메라 정면으로 Raycast를 발사해 플레이어가 바라보는 오브젝트를 판별합니다.
오브젝트 태그에 따라 문 이동, 열쇠 획득, 힌트 확인, 비밀번호 입력창 표시가 분기됩니다.

- 문 진입 및 퇴장
- 닫힌 문 안내 메시지
- 교수실, 실험실 자물쇠 확인
- 종이 단서 UI 표시
- 모니터 비밀번호 확인

<br>

### 씬 전환 후 위치 유지

`Player` 객체를 싱글톤으로 유지하고 `DontDestroyOnLoad`를 적용했습니다.
씬이 바뀌어도 열쇠 보유 상태와 현재 위치 정보가 유지되며, `StartPoint`에서 이동 후 시작 지점을 맞춥니다.

<br>

### 퍼즐과 열쇠 상태 관리

열쇠 획득 여부와 비밀번호 입력 결과에 따라 이동 가능한 공간이 달라집니다.
게임 내 주요 퍼즐은 자물쇠 입력 UI와 힌트 오브젝트를 중심으로 구성되어 있습니다.
